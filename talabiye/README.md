# طلبيّة: الفويس بيصير طلبية، والعنوان بيصير دبّوس

للي بيبيعوا عالإنستغرام والواتساب. البيّاع بيبعت فويس الزبون أو المحادثة، وبيطلعلو:
القطع والمقاسات والسعر، العنوان مع رابط الخريطة، شو ناقص لازم يسأل عنو، والرد جاهز يبعتو.
وبكبسة بيبعت للزبون رابط «دبّوس» ليحدد موقعو بالظبط، وبيبعت الطلبية للديليفري.

| الملف | شو هو |
|---|---|
| `index.html` | صفحة البيع |
| `app.html` | التطبيق: الطلبيات، والحسابات (مين بعدو، الربح، المصاريف، نسخة احتياطية)، وعداد الباقة |
| `pin.html` | صفحة الزبون ليحدد موقعو. بلا تسجيل، وبتحفظ عنوانو عتلفونو |
| `supabase/functions/talabiye-parse` | الخدمة اللي بتحلل الفويس بـ Gemini |
| `config.js` | الإعدادات: رابط الخدمة، رقمك، الأسعار |

بلا رابط خدمة، التطبيق بيشتغل **بوضع العرض** (بيطلّع طلبية تجريبية)، وهيدا بيكفي لتصوير فيديوهات وتفرجي الفكرة.

## الإعداد

1. **الخدمة (Gemini):** بنفس مشروع Supabase تبع نصيب، أو بمشروع جديد:
   - جيبي مفتاح من **aistudio.google.com ← Get API key**. استعملي حساب مدفوع (بفوترة)، لأن بالمجاني Google ممكن تستعمل الفويسات لتدريب نماذجها، ونحنا عم نوعد الزبائن إنو ما منحفظ شي.
   - **Edge Functions ← Secrets:** زيدي `GEMINI_API_KEY`.
   - انشري الخدمة: `supabase functions deploy talabiye-parse --no-verify-jwt`
     (أو من لوحة Supabase: **Edge Functions ← Deploy a new function**، والصقي `index.ts`، وطفّي **Verify JWT**).
   - التكلفة تقريباً: فويس دقيقة بيكلف أقل من سنت واحد.
2. **`config.js`:** حطي `PARSE_URL` (رابط الخدمة)، و`OWNER_WHATSAPP` (رقمك، مثلاً `9613123456`).
3. **النشر:** اسحبي مجلد `talabiye` كلو على **app.netlify.com/drop**، متل ما عملتي بتطبيق الشكاوى. غيّري اسم الموقع لـ `talabiye`.

## الأسبوع ١–٢: نتأكد إنو في طلب (قبل أي إعلان)
الهدف: **١٠ بيّاعين بيقولوا «بدي»، و٣ بيدفعوا سلف.** إذا ما صار هيك، منغيّر قبل ما نخسر.

**كيف تلاقي البيّاعين عالإنستغرام:** دوّري بـ `#lebanonshopping` و`#beirutboutique` و`#onlineshoplebanon` و`#توصيل_لكل_لبنان` و`#صنع_في_لبنان`. أحسن هدف: حساب عندو ١–٢٠ ألف متابع، وبالبايو «DM to order» أو رقم واتساب، يعني الطلبيات عم تجي عالواتساب.

**الرسالة الأولى (ما تبيعي، اسألي):**
> مرحبا 🌸 حبيت شغلكن كتير. سؤال صغير لأني عم بعمل أداة للي بيبيعوا أونلاين:
> الطلبيات اللي بتجيكن فويسات عالواتساب، كيف بتسجلوها؟ وبتضيعوا وقت بالعناوين مع الديليفري؟

**إذا جاوبوا:**
> عملت شي بيحوّل الفويس لطلبية مرتبة مع العنوان عالخريطة بـ ١٠ ثواني. فيني ابعتلك فيديو ٣٠ ثانية؟ وإذا عجبك، بتجربيه أسبوعين ببلاش.

**بعد التجربة:**
> كيف كانت؟ السنة كلها بـ ٧٩$، لحد ٦٠٠ طلبية بالشهر، ومعها الحسابات. وأول ٥٠ محل بيضل سعرن هيك. بتحبي احجزلك؟ (Whish / OMT / USDT)

بتبعتي **٢٠ رسالة باليوم**. ٢٠٠ رسالة بعشر أيام بيعطوا عادةً ٢٠–٤٠ رد، ومنهن بيطلعوا أول الزبائن.

**شركات الديليفري:** دوّري عالإنستغرام وغوغل على «delivery Lebanon». ابعتيلهن:
> مرحبا، كم طلبية بالأسبوع بتتأخر أو بترجع لأن العنوان مش واضح؟ عندي رابط بيبعتو البيّاع للزبون، والزبون بيحدد موقعو بكبسة. بتحبوا تجربوه ببلاش أسبوعين؟

## الأسبوع ٣–٦: المحتوى (مجاني)
حساب إنستغرام وتيكتوك باسم **طلبيّة**. ٤ فيديوهات بالأسبوع، كلها تصوير شاشة مع صوتك:

1. **«قبل وبعد»:** فويس دقيقتين مخربط ← ١٠ ثواني ← طلبية مرتبة. (هيدا الفيديو الأهم، أعمليه بـ ٥ نسخ مختلفة)
2. **«الديليفري ضاع»:** «حد الفرن بعد الجامع التاني» ← رابط دبّوس ← موقع بالظبط.
3. **«فويسات الزبائن»:** فويسات مضحكة (بإذن أصحابها أو مكتوبة من عندك) ومنشوف إذا طلبيّة بتفهمها. هيدا النوع بينتشر.
4. **«يوم من حياة بيّاعة»:** ٣٠ طلبية بيوم، ومن غير طلبيّة كانت بتاخد ساعتين.

أول ٣ ثواني بالفيديو هنّي كل شي. ابدأي دايماً بالمشكلة: «الزبونة بعتتلي فويس دقيقتين و...»

## الأسبوع ٥–١٢: الإعلانات (٢٠٠–٥٠٠$)
- **ما تبلشي إعلانات** قبل ما يكون عندك ٥ زبائن راضيين وفيديو جاب تفاعل طبيعي.
- Meta (إنستغرام + فيسبوك)، **Click-to-WhatsApp**، لبنان، ٢٢–٤٥ سنة.
  الاهتمامات: Small business، Online shopping، Instagram Shopping، Entrepreneurship.
- ابدأي بـ ٨–١٠$ باليوم على أفضل فيديو. إذا كلفة المحادثة أقل من ١$، زيدي. إذا أكتر من ٣$، غيّري الفيديو.
- الإحالة: كل محل بيجيب محل تاني، بياخد **٣ أشهر ببلاش**.
- **الدبّوس بيسوّق لحالو:** كل زبون بيفتح صفحة الدبّوس بيشوف تحت «بتبيع أونلاين؟ جرّبها لمحلك».

## الأرقام اللي لازم تراقبيها كل أسبوع
- رسائل انبعتت ← ردود ← تجارب ← دفعوا
- كم طلبية حللوا البيّاعين بالتجربة (إذا أقل من ٥ بالأسبوع، المنتج مش عم يحل مشكلتهن)
- كلفة المحادثة من الإعلان
