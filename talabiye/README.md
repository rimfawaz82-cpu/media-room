# طلبيّة: الفويس بيصير طلبية، والعنوان بيصير دبّوس

للي بيبيعوا عالإنستغرام والواتساب. البيّاع بيبعت فويس الزبون أو المحادثة، وبيطلعلو:
القطع والمقاسات والسعر، العنوان مع رابط الخريطة، شو ناقص لازم يسأل عنو، والرد جاهز يبعتو.
وبكبسة بيبعت للزبون رابط «دبّوس» ليحدد موقعو بالظبط، وبيبعت الطلبية للديليفري.

| الملف | شو هو |
|---|---|
| `index.html` | صفحة البيع |
| `app.html` | التطبيق: الطلبيات، والحسابات (مين بعدو، الربح، المصاريف، نسخة احتياطية)، وعداد الباقة |
| `wholesale.html` | طلبيّة للجملة: لائحة أصناف، مطابقة الطلبية، فاتورة، وطلبيات اليوم |
| `inbox.html` | صندوق مساعد واتساب: الطلبيات من الواتساب، والردود للموافقة |
| `pin.html` | صفحة الزبون ليحدد موقعو. بلا تسجيل، وبتحفظ عنوانو عتلفونو |
| `supabase/functions/talabiye-parse` | الخدمة اللي بتحلل الفويس بـ Gemini |
| `config.js` | الإعدادات: رابط الخدمة، رقمك، الأسعار |

بلا رابط خدمة، التطبيق بيشتغل **بوضع العرض** (بيطلّع طلبية تجريبية)، وهيدا بيكفي لتصوير فيديوهات وتفرجي الفكرة.

## الإعداد

1. **الخدمة (Gemini):** بنفس مشروع Supabase تبع نصيب، أو بمشروع جديد:
   - جيبي مفتاح من **aistudio.google.com ← Get API key**. استعملي حساب مدفوع (بفوترة)، لأن بالمجاني Google ممكن تستعمل الفويسات لتدريب نماذجها، ونحنا عم نوعد الزبائن إنو ما منحفظ شي.
   - **Edge Functions ← Secrets:** زيدي `GEMINI_API_KEY`.
   - انشري الخدمة: `supabase functions deploy talabiye-parse --no-verify-jwt`
     (أو من لوحة Supabase: **Edge Functions ← Deploy a new function**، والصقي `index.ts`، وطفّي **Verify JWT**).
   - التكلفة تقريباً: فويس دقيقة بيكلف أقل من سنت واحد.
2. **`config.js`:** حطي `PARSE_URL` (رابط الخدمة)، و`OWNER_WHATSAPP` (رقمك، مثلاً `9613123456`).
3. **النشر:** اسحبي مجلد `talabiye` كلو على **app.netlify.com/drop**، متل ما عملتي بتطبيق الشكاوى. غيّري اسم الموقع لـ `talabiye`.

# مساعد واتساب

الزبون بيبعت عرقم المحل رسالة أو فويس أو موقع، والمساعد بيفهمها وبيكتب الطلبية والرد. المحل بيشوف كل شي بـ **`inbox.html`** وبيكبس «ابعت الرد».

```
الزبون ← واتساب (Meta) ← talabiye-whatsapp ← Gemini بيفهم ← wa_orders
                                                    ↓
                           inbox.html (المحل بيراجع) ← talabiye-send ← واتساب ← الزبون
```

- **الرد ما بينبعت لحالو** إلا إذا شغّلتي «الرد بينبعت لحالو» بالإعدادات. بالبداية خلّيه مطفي.
- **الدبّوس:** إذا العنوان ناقص، المساعد بيطلب من الزبون يبعت موقعو من زر «الموقع» بالواتساب، والموقع بيوصل عالطلبية لحالو.
- **كل زبون إلو طلبية مفتوحة** لـ ٢٤ ساعة. كل رسالة جديدة بتزيد أو بتعدّل عليها.
- **لائحة الأصناف والأسعار** (اختياري، من الإعدادات) بتخلّي المساعد يحط الأسعار الصح، وما يبيع شي مش موجود.
- **الحماية:** الخدمة بتتأكد إنو كل رسالة جايي من Meta (توقيع `WHATSAPP_APP_SECRET`)، والصندوق بيفتح بس للإيميلات اللي بجدول `talabiye_members`.

| الملف | شو هو |
|---|---|
| `supabase/whatsapp.sql` | الجداول والحماية |
| `supabase/functions/talabiye-whatsapp` | بيستقبل رسائل واتساب، بيفهمها، وبيحفظ الطلبية |
| `supabase/functions/talabiye-send` | بيبعت الرد اللي وافقتي عليه |
| `supabase/functions/_shared/whatsapp.ts` | Gemini + Meta API |
| `inbox.html` | صندوق الطلبيات للمحل |

## الإعداد

**١. Supabase** (نفس مشروع نصيب):
1. **SQL Editor:** الصقي `supabase/whatsapp.sql`، غيّري الإيميل بآخر الملف، وكبسي Run.
2. **Authentication ← Users:** اعملي حساب بنفس الإيميل.
3. انشري الخدمتين:
   ```
   supabase functions deploy talabiye-whatsapp --no-verify-jwt
   supabase functions deploy talabiye-send
   ```
4. **Edge Functions ← Secrets:** `GEMINI_API_KEY`، `WHATSAPP_VERIFY_TOKEN` (كلمة بتختاريها)، `WHATSAPP_APP_SECRET`، `WHATSAPP_TOKEN`، `WHATSAPP_PHONE_ID`. واختياري: `GEMINI_MODEL` و`GRAPH_VERSION`.
5. بـ `config.js`: حطي `SUPABASE_URL` و`SUPABASE_ANON_KEY` (من Project Settings ← API).

**٢. Meta (developers.facebook.com):**
1. **My Apps ← Create App**، واختاري الاستعمال تبع WhatsApp أو نوع Business.
2. **WhatsApp ← API Setup:** بيعطيكِ **رقم تجربة ببلاش** وتوكن مؤقت (٢٤ ساعة). زيدي رقمك كمستلم (لحد ٥ أرقام بالتجربة). خدي **Phone number ID**.
3. **WhatsApp ← Configuration ← Webhook:**
   - Callback URL: `https://<project>.supabase.co/functions/v1/talabiye-whatsapp`
   - Verify token: نفس `WHATSAPP_VERIFY_TOKEN`
   - Verify and save، وبعدين اشتركي بحقل **messages**.
4. **App settings ← Basic:** خدي **App secret** وحطيه بـ `WHATSAPP_APP_SECRET`.
5. **التوكن الدائم:** Business Settings ← System users ← زيدي واحد، أعطيه التطبيق بصلاحيات `whatsapp_business_messaging` و`whatsapp_business_management`، واعملي Generate token. هيدا بيصير `WHATSAPP_TOKEN`.

**٣. جربي:** من تلفونك، ابعتي رسالة أو فويس لرقم التجربة. الطلبية لازم تطلع بـ `inbox.html` خلال ثواني.

**٤. الرقم الحقيقي (بعد التجربة):** زيدي رقم المحل بـ WhatsApp Manager. إذا بدك نفس الرقم يضل شغّال على تطبيق واتساب بزنس (Coexistence)، اتأكدي إنو الخيار بيطلع وقت التسجيل. وزيدي طريقة دفع بـ Billing لما تتخطي الرسائل المجانية.

**انتبهي:**
- واتساب بيسمح بالرد العادي بس **خلال ٢٤ ساعة** من آخر رسالة من الزبون. بعدها لازم رسالة جاهزة (template)، وهيدي مش مبنية بعد.
- Meta بتوقف نسخ الـ API القديمة. إذا طلع خطأ فيه «version»، حطي النسخة الجديدة بـ `GRAPH_VERSION`.
- الأسعار: من ١ تشرين الأول ٢٠٢٦، أول ١٠٠٠ رد بالشهر لكل رقم ببلاش، وبعدها بيندفعوا (بحسب المصادر اللي لقيناها، اتأكدي من صفحة Meta).

# طلبيّة للجملة (الهدف الجديد)

محلات الجملة والمحلات الأونلاين الكبيرة بيجيهن ١٠٠–٢٠٠ طلبية باليوم، كتير منها فويسات عالواتساب، وموظف أو اتنين بس عم ينقلوا ويطابقوا مع لائحة الأسعار.
**`wholesale.html`**: بترفعي لائحة أصناف المحل (Excel)، بتلصقي طلبية الزبون، وبتطلع الفاتورة مطابقة عالأصناف والأسعار. بتنحفظ، وبتنبعت عالواتساب، وبتنسخ للإكسل.

- بلا ذكاء اصطناعي، بتشتغل بقواعد بسيطة عالرسائل الواضحة («٥ كراتين زيت، كرتونتين معكرونة»)، وبتفهم «مي» و«كرتونتين» و«نص كرتونة».
- مع خدمة Gemini (`PARSE_URL`)، بتفهم الفويس والرسائل المخربطة، ومنبعتلها لائحة الأصناف لتطابق عليها.
- كل صنف مش أكيد بيطلع بالأحمر، والموظف بيختارو من قائمة.

## التجربة: ٥ محلات جملة، أسبوعين
1. اطلبي من كل محل **لائحة أصنافو وأسعارو** (Excel أو صورة) و**١٠ طلبيات حقيقية** (رسائل وفويسات) من زبائنو.
2. حطي لائحتو بـ «الأصناف»، ومرّقي طلبياتو. سجّلي قديش صنف طلع صح من أول مرة.
3. فرجيه النتيجة على شغلو هوي، مش على المثال.
4. **إذا ٢ من الـ ٥ قالوا «بدنا»** ووافقوا يجربوا أسبوع بشغلهن اليومي، منبني النسخة الكاملة.

## أسئلة لصاحب المحل
1. كم طلبية بتجيكن باليوم؟ كم منها بالواتساب؟ وكم منها فويس؟
2. مين بيدخّلها؟ قديش بياخد وقت؟ فرجيني كيف.
3. وين بتسجلوها: دفتر، Excel، برنامج؟ شو اسم البرنامج؟
4. آخر غلطة بطلبية (صنف غلط، كمية غلط)، شو كلّفت؟
5. إذا الطلبية بتطلع فاتورة جاهزة بثواني، والموظف بس بيراجع، قديش بيوفّر عليكن؟
6. قديش بتدفعوا بالشهر كرمال هيك شي؟ (اسمعي الرقم منو قبل ما تقولي سعرنا)

**سجّلي لكل محل:** عدد الطلبيات باليوم، البرنامج اللي عندو، نسبة الأصناف اللي طلعت صح، والرقم اللي قالو.

## تسعير مقترح (بعد التجربة)
- **١٠٠–٣٠٠$ بالشهر** حسب عدد الطلبيات. المقارنة: معاش موظف إدخال ٣٠٠–٥٠٠$.
- مساعد واتساب (الفويس بيوصل ويتحلل لحالو) جزء أساسي من الباقة للجملة، لأن ما حدا رح يشارك ٢٠٠ فويس باليوم بإيدو. كلفة رسائل Meta عليه بتنحسب بالسعر.
- لـ ٣٠٠٠$ صافي بالشهر: تقريباً ٢٥–٣٠ محل. لـ ٥٠٠٠$: تقريباً ٤٠–٤٥.

## الأسبوع ١–٢: نتأكد إنو في طلب (قبل أي إعلان)

**كيف تلاقي البيّاعين عالإنستغرام:** دوّري بـ `#lebanonshopping` و`#beirutboutique` و`#onlineshoplebanon` و`#توصيل_لكل_لبنان` و`#صنع_في_لبنان`. أحسن هدف: حساب عندو ١–٢٠ ألف متابع، وبالبايو «DM to order» أو رقم واتساب، يعني الطلبيات عم تجي عالواتساب.

**الرسالة الأولى (ما تبيعي، اسألي):**

> الطلبيات اللي بتجيكن فويسات عالواتساب، كيف بتسجلوها؟ وبتضيعوا وقت بالعناوين مع الديليفري؟

**إذا جاوبوا:**
> عملت شي بيحوّل الفويس لطلبية مرتبة مع العنوان عالخريطة بـ ١٠ ثواني. فيني ابعتلك فيديو ٣٠ ثانية؟ وإذا عجبك، بتجربيه أسبوعين ببلاش.

**بعد التجربة:**

بتبعتي **٢٠ رسالة باليوم**. ٢٠٠ رسالة بعشر أيام بيعطوا عادةً ٢٠–٤٠ رد، ومنهن بيطلعوا أول الزبائن.

## الأسبوع ٣–٦: المحتوى (مجاني)
حساب إنستغرام وتيكتوك باسم **طلبيّة**. ٤ فيديوهات بالأسبوع، كلها تصوير شاشة مع صوتك:

1. **«قبل وبعد»:** فويس دقيقتين مخربط ← ١٠ ثواني ← طلبية مرتبة. (هيدا الفيديو الأهم، أعمليه بـ ٥ نسخ مختلفة)
2. **«الديليفري ضاع»:** «حد الفرن بعد الجامع التاني» ← رابط دبّوس ← موقع بالظبط.
3. **«فويسات الزبائن»:** فويسات مضحكة (بإذن أصحابها أو مكتوبة من عندك) ومنشوف إذا طلبيّة بتفهمها. هيدا النوع بينتشر.
4. **«يوم من حياة بيّاعة»:** ٣٠ طلبية بيوم، ومن غير طلبيّة كانت بتاخد ساعتين.

أول ٣ ثواني بالفيديو هنّي كل شي. ابدأي دايماً بالمشكلة: «الزبونة بعتتلي فويس دقيقتين و...»

## الأسبوع ٥–١٢: الإعلانات (٢٠٠–٥٠٠$)
- **ما تبلشي إعلانات** قبل ما يكون عندك ٥ زبائن راضيين وفيديو جاب تفاعل طبيعي.
- Meta (إنستغرام + فيسبوك)، **Click-to-WhatsApp**، لبنان، ٢٢–٤٥ سنة.
  الاهتمامات: Small business، Online shopping، Instagram Shopping، Entrepreneurship.
- ابدأي بـ ٨–١٠$ باليوم على أفضل فيديو. إذا كلفة المحادثة أقل من ١$، زيدي. إذا أكتر من ٣$، غيّري الفيديو.
- الإحالة: كل محل بيجيب محل تاني، بياخد **٣ أشهر ببلاش**.
- **الدبّوس بيسوّق لحالو:** كل زبون بيفتح صفحة الدبّوس بيشوف تحت «بتبيع أونلاين؟ جرّبها لمحلك».
