# دفتر مزاد نصيب — تطبيق ويب (PWA)

نسخة من دفتر نصيب بتشتغل كتطبيق مستقل. بتنفتح على Chrome وبتنزل على شاشة الهوم.
البيانات محفوظة أونلاين بـ Supabase ومشتركة بين الشركاء، وبتوصل التعديلات فوراً لكل الأجهزة.

## الإعداد (مرة وحدة)
1. **الجداول:** بـ Supabase افتح **SQL Editor ← New query**، والصق محتوى [`supabase.sql`](supabase.sql).
   قبل ما تكبّس **Run**، غيّر الإيميلين بآخر الملف لإيميلك وإيميل شريكك.
2. **الحسابات:** **Authentication ← Users ← Add user ← Create new user**.
   حط الإيميل وكلمة السر، وعلّم على **Auto Confirm User**. عيدها للشريك.
3. **نقل البيانات القديمة:** من دفتر claude.ai روح على **الإعدادات ← تنزيل نسخة احتياطية**.
   بعدين من التطبيق: **الإعدادات ← استرجاع من ملف**.

إضافة شريك جديد: زيد إيميله بجدول `naseeb_members` واعمله حساب بـ Authentication.

## التنزيل على الهوم
- **أندرويد (Chrome):** ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات
- رابط Supabase موجود بـ [`config.js`](config.js). إذا فضّيته، بيرجع التطبيق يحفظ على الجهاز بس.
- «Claude يقرا الكرتونة» بتشتغل بس جوّا claude.ai.
- التطبيق بينفتح بلا إنترنت، بس لتشوف البيانات أو تسجّل بدّك إنترنت.
