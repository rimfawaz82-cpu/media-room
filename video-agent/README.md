# وكيل الفيديو والمونتاج (Video Agent)

مهنة **صانع الفيديو والمونتير**، كإنسان يعمل وحده لعدة جهات (بلدية، جامعة، مطعم، متجر)، مفكّكة إلى 20 مهارة.
كل مهارة في `skills/<اسم>/SKILL.md` وتصلح agent مستقلاً، أو تعمل كلها تحت `video-director`.

**المعدات المفترضة:** Canon 5D Mark III + Samsung Galaxy S26 Ultra، والمونتاج على CapCut (موبايل وكمبيوتر).

## الدورة الكاملة

```
التحضير مع الجهة ← الجمهور ← الفكرة والهوك ← (القصة الطويلة) ← النص
  ← التصوير (+ الفعاليات) ← الكلام أمام الكاميرا ← الصوت
  ← المونتاج العملي + لغة المونتاج ← اللون ← العناوين والجرافيك
  ← أدوات الذكاء الاصطناعي ← النسخ لكل منصة ← الحقوق ← النشر
  ← الأرقام ← الذوق ← التطور المهني ← (يرجع للبداية)
```

## المهارات
