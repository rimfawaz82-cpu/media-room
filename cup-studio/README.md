# كوبي · استوديو تصميم الأكواب والبوكسات 3D

الزبون بيصمّم كوبه وبوكس هديته بخطوات بسيطة وبيشوفهم 3D قبل ما يطلب.

## الصفحات
- `index.html` — الاستوديو للزبون: المناسبة ← الكوب ← لمستك (اسم، خط، زخرفة، ملصق) ← البوكس ← الإضافات ← الطلب (واتساب).
- `admin.html` — لوحة التحكم: الأكواب، الألوان، الزخارف (مع رفع صور)، الملصقات، البوكسات بالقياسات، الشرائط، الإضافات، المناسبات، الأسعار، رقم الواتساب.

## التشغيل
ملفات ثابتة بدون build. لازم تنفتح من سيرفر (مش `file://`) لأنها ES modules:
```
cd cup-studio && python3 -m http.server 8080
```
Three.js محفوظة بـ `vendor/` (نسخة 0.160.0) فما في اعتماد على CDN.

## الكتالوج
`catalog.js` فيه القيم الافتراضية. التعديلات من لوحة التحكم بتنحفظ بالمتصفح (localStorage).
لتطلع لكل الزباين: «تصدير JSON» من لوحة التحكم وحط الملف `catalog.json` جنب `index.html`.
الخطوة الجاية: ربط الكتالوج والطلبات بـ Supabase (متل مشروع نصيب) لحتى تتعدّل من أي جهاز.
