# 🎬 أكاديمية الفيديو

مشروع تعليمي فقط لتعلّم صناعة الفيديو باحتراف، ببساطة وخطوة بخطوة، مع Claude كمدرّب.

## كيف تبدأ
افتح Claude Code داخل هذا المجلد (`video-academy/`) واكتب:

> علمني فيديو من البداية

سيسألك Claude 4 أسئلة لتحديد مستواك، ثم يبدأ معك المنهج.

## المنهج (12 أسبوعًا)
1. أساسيات الكاميرا
2. التكوين
3. الإضاءة
4. الصوت
5. اللقطات والتخطيط
6. السرد البصري
7. الخطّاف والقصة
8. المونتاج الأساسي
9. الانتقالات
10. الألوان
11. الوقوف أمام الكاميرا
12. مشروع التخرج

## المهارات في هذا المشروع
| المهارة | الموضوع |
|---|---|
| `video-learning-path` | المنهج وتحديد المستوى ومراجعة التمارين |
| `video-camera-basics` | إعدادات الكاميرا والجوال، والتكوين، والحركة |
| `video-lighting-coach` | الإضاءة من النافذة إلى الإضاءة الثلاثية |
| `video-visual-storytelling` | القصة بالصورة، و B-roll، وتسلسل اللقطات |
| `video-transitions-guide` | الانتقالات في المونتاج وداخل الكاميرا |
| `video-color-grading` | تصحيح الألوان وتدريجها |

وتعمل معها مهارات الفيديو المثبتة في حسابك: التخطيط، والصوت، والقصة، والمونتاج، والكاميرا، والسكربت.

## ملفاتك
- `progress.md`: تقدّمك (ينشئه Claude تلقائيًا).
- `exercises/`: تمارينك حسب الأسبوع.
