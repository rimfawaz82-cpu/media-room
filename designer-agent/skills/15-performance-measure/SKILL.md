# القياس والتعلّم (Performance & Measurement)

## المبدأ
المصمّم الحديث لا يتوقف عند "تم النشر". الذوق يتحسّن أسرع حين يُختبر بالأرقام — لكن **الأرقام تقيس، والذوق يقرّر**.

## اختر المؤشر حسب الهدف
| الهدف | المؤشرات |
|-------|----------|
| الانتباه/الوصول | معدل إيقاف التمرير (Thumb-stop: مشاهدات 3 ثوانٍ ÷ الظهور)، الوصول، الظهور |
| التفاعل | معدل التفاعل، **الحفظ والمشاركة** (أقوى من الإعجاب)، التعليقات |
| الفعل | نسبة النقر CTR، التحويلات، تكلفة النتيجة |
| الفيديو/الموشن | نسبة الاحتفاظ ومنحنى المشاهدة، متوسط مدة المشاهدة |
| الكاروسيل | نسبة التمرير للشريحة الأخيرة |
| العلامة | التعرّف بدون شعار، استطلاعات التذكّر |

## تصميم اختبار A/B بصري
1. **متغيّر واحد** في كل اختبار (الصورة أو العنوان أو اللون أو التكوين) — وإلا لن تعرف السبب.
2. فرضية مكتوبة: "الوجه البشري سيرفع CTR مقارنة بصورة المنتج لأن ___".
3. نفس الجمهور والميزانية والتوقيت (أدوات الاختبار في مدير الإعلانات أفضل من المقارنة بين منشورات عضوية).
4. حجم عيّنة كافٍ قبل الحكم — لا تحكم من 200 ظهور.
5. سجّل النتيجة في **مكتبة دروس**.

## مكتبة الدروس (Creative learnings)
لكل اختبار: التاريخ، المنصة، الفرضية، النسختان (صورة)، النتيجة، الدرس، الثقة (منخفضة/متوسطة/عالية). راجع المكتبة قبل كل بريف جديد.

## تحذيرات
- خوارزميات المنصات تتغير؛ لا تعمّم نتيجة شهر واحد للأبد.
- المحتوى العضوي يتأثر بالتوقيت والموضوع أكثر من التصميم أحياناً — افصل العوامل.
- لا تجعل الأرقام قصيرة المدى تقتل بناء العلامة طويل المدى (Binet & Field: التوازن بين بناء العلامة والتفعيل).

## المخرجات
تقرير أداء (المؤشرات مقابل الهدف)، تفسير، 3 دروس، واقتراح الاختبار التالي.
