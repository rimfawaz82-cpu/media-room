# الإنتاج والتسليم (Production & Export)

## المبدأ
تصميم ممتاز بملف سيئ = تصميم فاشل عند العميل أو المطبعة. الاحتراف يظهر في الملفات التي لا يراها أحد.

## الصيغ ومتى تُستخدم
| الاستخدام | الصيغة | ملاحظات |
|-----------|--------|---------|
| صور سوشال | JPG (جودة 80–90%) أو PNG | sRGB دائماً |
| شفافية/شعارات للويب | SVG، PNG | SVG للشعارات والأيقونات |
| ويب حديث | WebP / AVIF | أخف بكثير |
| طباعة | PDF/X-1a أو PDF/X-4 | CMYK، خطوط مضمّنة |
| فيديو سوشال | MP4 (H.264/H.265) | 1080p على الأقل |
| حركة خفيفة للتطبيقات | Lottie (JSON) / Rive | |
| ملف المصدر | .fig / .psd / .ai / .indd | منظم ومسمّى |

## الطباعة
- **فضاء اللون:** CMYK بملف التعريف الذي تطلبه المطبعة (مثلاً FOGRA39/51 أو GRACoL). الألوان الزاهية في RGB تبهت في CMYK — راجع مبكراً.
- **الدقة:** 300dpi بالحجم الفعلي (أقل للوحات الكبيرة التي تُرى من بعيد).
- **الهوامش:** Bleed عادة 3mm، ومنطقة آمنة داخلية 3–5mm، مع علامات القص.
- **الأسود الغني (Rich black)** للمساحات الكبيرة، والأسود 100K فقط للنصوص الصغيرة.
- **الخطوط:** مضمّنة أو محوّلة لمخططات (Outlines) — مع الاحتفاظ بنسخة قابلة للتعديل.
- **بروفة (Proof)** مطبوعة قبل الكمية الكاملة.

## الشاشة
- sRGB، الحجم الدقيق للمنصة (لا تترك المنصة تعيد التحجيم بشكل سيئ).
- تصدير @2x للواجهات الحادة، وضغط بدون فقد ملحوظ.

## تنظيم الملف
- طبقات/إطارات مسمّاة بوضوح، لا "Layer 37".
- استخدام المكونات والأنماط (Styles/Variables) لا قيماً يدوية.
- **تسمية الملفات:** `العميل_المشروع_المنصة_المقاس_v03_2026-10-16.jpg` — بدون "final_final2".
- أرشفة: المصدر + الخطوط (أو روابط ترخيصها) + الصور المرتبطة + الصادرات.

## التسليم للمطورين (Handoff)
مواصفات المسافات والألوان والخطوط كـ Tokens، الأصول المصدّرة، الحالات (hover/disabled/empty/error)، السلوك المتجاوب، والحركة (المدة والمنحنى). استخدم Dev Mode في Figma أو ما يعادله.

## قائمة فحص قبل الإرسال
- [ ] المقاسات والصيغ مطابقة لقائمة التسليمات في البريف.
- [ ] فضاء اللون صحيح لكل وجهة.
- [ ] لا صور منخفضة الدقة ولا روابط مفقودة.
- [ ] الإملاء مراجَع مرة أخيرة في الملف المصدَّر نفسه.
- [ ] التسمية والمجلدات منظّمة.

## المخرجات
قائمة الملفات المسلّمة (الاسم، المقاس، الصيغة، فضاء اللون) + ملاحظات للمطبعة/المطور.
