# وكيل المصمّم (Designer Agent)

هذا المجلد يفكّك مهنة **المصمّم الجرافيكي / صانع المحتوى البصري** — كإنسان يعمل في غرفة إعلام — إلى مهارات منفصلة.
كل مهارة في ملف خاص بها (`skills/<اسم>/SKILL.md`) ويمكن تحويلها إلى agent مستقل، أو استخدامها كلها معاً تحت "المدير الفني" (الملف `00-art-director`).

## كيف يفكّر المصمّم المحترف (الدورة الكاملة)

```
البريف ← الجمهور ← الفكرة ← التكوين ← الخط ← اللون ← الصورة ← الهوية
   ← الكتابة على التصميم ← مقاسات المنصة والحركة ← أدوات الذكاء الاصطناعي
   ← النقد والتكرار ← الإنتاج والتسليم ← العرض على العميل ← القياس ← (يرجع للبريف)
```

النظرية الأم التي تحكم الدورة: **Double Diamond** (المجلس البريطاني للتصميم):
اكتشف (Discover) ← حدّد (Define) ← طوّر (Develop) ← سلّم (Deliver).
أول ماسة: نفهم المشكلة الصحيحة. ثاني ماسة: نصمّم الحل الصحيح.

## كيف تبني الـ agent

1. **وكيل واحد شامل**: انسخ مجلد `skills/` كاملاً إلى `.claude/skills/` في مشروعك؛ المدير الفني يستدعي الباقي.
2. **وكيل لكل مهارة**: كل `SKILL.md` فيه رأس (frontmatter) بالاسم والوصف، ومكتوب كتعليمات تشغيل جاهزة (دور، خطوات، قائمة فحص، شكل المخرجات).
3. **سلسلة (Pipeline)**: مخرجات كل مهارة مصمّمة لتكون مدخلات التالية (بريف ← جمهور ← مفاهيم ← ...).

> ملاحظة: هذه المهارات تكمّل مهارات الفيديو الموجودة لديك (`video-script-writer`, `video-shot-planner`, ...) — هنا الجانب البصري الثابت والهوية والتصميم.
